## 一、基础运算与 i 的性质

1. 计算：$\frac{(1 + i)^{2}}{1 - i} + (2 + i)(2 - i)$。<span class="ans-wrap"><span class="ans">$4 + i$</span></span>

2. 已知 $i$ 为虚数单位，求 $i + i^{2} + i^{3} + \ldots + i^{2026}$ 的值。<span class="ans-wrap"><span class="ans">$i - 1$</span></span>

3. 若复数 $z = \frac{1 + 2i}{i}$，求 $z$ 的实部与虚部之和。<span class="ans-wrap"><span class="ans">$1$</span></span>

4. 已知 $a,b \in \mathbb{R}$，且 $(a + i)(1 - i) = b + 2i$，求 $a$ 和 $b$ 的值。<span class="ans-wrap"><span class="ans">$a = -1,\; b = 0$</span></span>

5. 设 $z = \frac{2}{1 + i}$，求 $z$ 的共轭复数 $\bar{z}$。<span class="ans-wrap"><span class="ans">$1 + i$</span></span>

6. 若复数 $z = (m^{2} - 1) + (m - 1)i$ 是纯虚数，求实数 $m$ 的值。<span class="ans-wrap"><span class="ans">$m = -1$</span></span>

7. 已知 $z = \frac{1 - i}{(1 + i)^{2}}$，计算 $|z|$ 的值。<span class="ans-wrap"><span class="ans">$\dfrac{\sqrt2}{2}$</span></span>

## 二、复数的模与几何性质

8. 在复平面内，复数 $z = \frac{1}{2 - i}$ 对应的点位于第几象限？<span class="ans-wrap"><span class="ans">第一象限</span></span>

9. 已知复数 $z$ 满足 $|z + i| = |z - 1|$，写出复数 $z$ 在复平面内对应点的轨迹方程。<span class="ans-wrap"><span class="ans">$x + y = 0$</span></span>

10. 若 $|z| = 1$，求 $|z - (3 + 4i)|$ 的最大值。<span class="ans-wrap"><span class="ans">$6$</span></span>

11. 已知 $z_{1} = 1 + i$，$z_{2} = 3 - i$，求线段 $z_{1}z_{2}$ 的中点在复平面内对应的复数。<span class="ans-wrap"><span class="ans">$2$</span></span>

12. 设 $z \in \mathbb{C}$，若 $|z| = z + 1 + 2i$，求复数 $z$。<span class="ans-wrap"><span class="ans">$\dfrac32 - 2i$</span></span>

13. 已知复数 $z$ 满足 $|z| = 2$，求 $z \cdot \bar{z}$ 的值。<span class="ans-wrap"><span class="ans">$4$</span></span>

14. 若复数 $z$ 对应的点在直线 $y = 2x$ 上，且实部为 $1$，求 $|z|$。<span class="ans-wrap"><span class="ans">$\sqrt5$</span></span>

## 三、实系数一元二次方程的解法

15. 在复数范围内解方程：$x^{2} + 4x + 5 = 0$。<span class="ans-wrap"><span class="ans">$-2 \pm i$</span></span>

16. 已知 $1 - 2i$ 是关于 $x$ 的实系数一元二次方程 $x^{2} + bx + c = 0$ 的一个根，求 $b + c$ 的值。<span class="ans-wrap"><span class="ans">$3$</span></span>

17. 设 $z$ 是虚数，且 $z + \dfrac{1}{z} = 1$，求 $|z|$ 的值。<span class="ans-wrap"><span class="ans">$1$</span></span>

18. 已知 $z^{2} = 3 + 4i$，求复数 $z$。<span class="ans-wrap"><span class="ans">$\pm(2 + i)$</span></span>

19. 若复数 $z$ 满足 $z^{2} + |z|^{2} = 2 + 4i$，求 $z$。<span class="ans-wrap"><span class="ans">$1 + 2i$ 或 $-1 - 2i$</span></span>

20. 已知 $z_{1},z_{2}$ 为共轭复数，且 $(z_{1} + z_{2})^{2} - z_{1}z_{2} = 3$，若 $z_{1}$ 的实部为 $1$，求 $z_{1}$。<span class="ans-wrap"><span class="ans">$z_{1} = 1$</span></span>
