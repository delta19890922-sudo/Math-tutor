# 初一上册数学讲义

## 第一章 有理数

### 1.1 正数和负数

**正数**：大于 0 的数叫做正数。如 3, 1.5, 2/3 等。

**负数**：在正数前面加上负号 "-" 的数叫做负数。如 -3, -1.5, -2/3 等。

**注意**：
- 0 既不是正数，也不是负数。
- 正数前面的正号 "+" 通常省略不写。
- 用正数和负数可以表示具有相反意义的量。例如：收入 50 元记作 +50 元，支出 30 元记作 -30 元。

### 1.2 有理数的分类

有理数按定义分类：

```
有理数
├── 整数
│   ├── 正整数（1, 2, 3, ...）
│   ├── 0
│   └── 负整数（-1, -2, -3, ...）
└── 分数
    ├── 正分数（1/2, 2/3, 3.5, ...）
    └── 负分数（-1/2, -2/3, -3.5, ...）
```

有理数按符号分类：

```
有理数
├── 正有理数
│   ├── 正整数
│   └── 正分数
├── 0
└── 负有理数
    ├── 负整数
    └── 负分数
```

### 1.3 数轴

规定了 **原点、正方向和单位长度** 的直线叫做数轴。

数轴的三要素：
1. **原点** —— 表示数 0 的点
2. **正方向** —— 通常取向右为正方向
3. **单位长度** —— 适当选取的长度单位

数轴上的点与有理数的关系：
- 正数在原点的右边，负数在原点的左边
- 任何一个有理数都可以用数轴上的一个点来表示
- 数轴上的点不一定都表示有理数

### 1.4 相反数

只有 **符号不同** 的两个数叫做互为相反数。

- 相反数是 **成对出现** 的
- 数 a 的相反数是 -a
- 0 的相反数是 0
- 在数轴上，互为相反数的两个数位于原点的两侧，且到原点的距离相等

**性质**：若 a 与 b 互为相反数，则 a + b = 0。

### 1.5 绝对值

数轴上表示数 a 的点到原点的距离叫做数 a 的绝对值，记作 |a|。

**绝对值的性质**：
$$
|a| =
\begin{cases}
a, & a > 0 \\
0, & a = 0 \\
-a, & a < 0
\end{cases}
$$

**重要性质**：
- |a| ≥ 0（绝对值是非负数）
- 若 |a| = |b|，则 a = ±b
- 若 |a| = a，则 a ≥ 0
- 若 |a| = -a，则 a ≤ 0

### 1.6 有理数的大小比较

1. 在数轴上，右边的数总比左边的数大
2. 正数 > 0 > 负数
3. 两个负数，绝对值大的反而小

### 1.7 有理数的运算

#### 加法法则

1. 同号两数相加，取相同的符号，并把绝对值相加
2. 异号两数相加，取绝对值较大的符号，并用较大的绝对值减去较小的绝对值
3. 互为相反数的两个数相加得 0
4. 一个数同 0 相加，仍得这个数

**加法运算律**：
- 交换律：a + b = b + a
- 结合律：(a + b) + c = a + (b + c)

#### 减法法则

减去一个数，等于加上这个数的相反数：
$$
a - b = a + (-b)
$$

#### 乘法法则

1. 同号得正，异号得负，并把绝对值相乘
2. 任何数与 0 相乘都得 0

**乘法运算律**：
- 交换律：a × b = b × a
- 结合律：(a × b) × c = a × (b × c)
- 分配律：a × (b + c) = a × b + a × c

#### 除法法则

1. 除以一个不等于 0 的数，等于乘以这个数的倒数
2. 两数相除，同号得正，异号得负，并把绝对值相除
3. 0 除以任何非 0 的数都得 0

#### 乘方

求 n 个相同因数的积的运算叫做乘方，记作 $a^n$。

$$
a^n = \underbrace{a \times a \times \cdots \times a}_{n\text{个}}
$$

其中 a 叫做 **底数**，n 叫做 **指数**，$a^n$ 叫做 **幂**。

**运算法则**：
- 正数的任何次幂都是正数
- 负数的奇次幂是负数，负数的偶次幂是正数
- 0 的正整数次幂都是 0

#### 科学记数法

把一个数写成 $a \times 10^n$ 的形式（其中 $1 \leq |a| < 10$，n 为整数），叫做科学记数法。

#### 有理数混合运算的顺序

1. 先乘方，再乘除，最后加减
2. 同级运算从左到右依次进行
3. 如有括号，先做括号内的运算（小括号 → 中括号 → 大括号）

## 第二章 整式的加减

### 2.1 用字母表示数

用字母表示数可以简明地表达数量关系。

**例**：
- 加法交换律：a + b = b + a
- 乘法分配律：a(b + c) = ab + ac
- 路程公式：s = vt（s 为路程，v 为速度，t 为时间）

### 2.2 代数式

用运算符号把数和字母连接而成的式子叫做代数式。

**注意**：单独的一个数或一个字母也是代数式。

**书写规范**：
- 数字与字母相乘时，数字写在字母前面，乘号省略
- 除法运算写成分数形式
- 带分数要化为假分数

### 2.3 单项式

由数与字母的 **积** 组成的代数式叫做单项式。单独的一个数或一个字母也是单项式。

- **系数**：单项式中的数字因数
- **次数**：所有字母的指数之和

**例**：
- $-3x^2y$：系数为 -3，次数为 2 + 1 = 3
- $5$：系数为 5，次数为 0
- $-x$：系数为 -1，次数为 1

### 2.4 多项式

几个单项式的 **和** 叫做多项式。

- **项**：每个单项式叫做多项式的项
- **常数项**：不含字母的项
- **次数**：次数最高的项的次数

**例**：$3x^2 - 2x + 5$ 是二次三项式，各项为 $3x^2$、$-2x$、$5$，常数项为 5，次数为 2。

### 2.5 整式

**单项式** 与 **多项式** 统称为整式。

### 2.6 同类项

所含字母相同，并且相同字母的指数也相同的项叫做同类项。

**注意**：
- 几个常数项也是同类项
- 同类项与系数无关，与字母的排列顺序无关

### 2.7 合并同类项

将同类项合并成一项，叫做合并同类项。

**法则**：系数相加作为新系数，字母和字母的指数不变。

**步骤**：
1. 找出同类项
2. 利用交换律、结合律将同类项放在一起
3. 合并同类项

### 2.8 去括号法则

1. 括号前面是 "+" 号，去括号后括号内的各项 **不变号**
2. 括号前面是 "-" 号，去括号后括号内的各项 **都变号**

$$
a + (b - c) = a + b - c
$$
$$
a - (b - c) = a - b + c
$$

### 2.9 整式的加减运算

整式加减的实质就是 **去括号** 和 **合并同类项**。

**一般步骤**：
1. 如果有括号，先去括号
2. 找出同类项
3. 合并同类项

**例**：计算 $(3x^2 + 2x - 1) - (x^2 - 3x + 2)$

解：
$$
\begin{aligned}
&= 3x^2 + 2x - 1 - x^2 + 3x - 2 \\
&= (3x^2 - x^2) + (2x + 3x) + (-1 - 2) \\
&= 2x^2 + 5x - 3
\end{aligned}
$$

## 第三章 一元一次方程

### 3.1 方程的概念

含有 **未知数** 的 **等式** 叫做方程。

**方程必须具备两个条件**：
1. 含有未知数
2. 是等式

### 3.2 一元一次方程

只含有一个未知数（元），未知数的次数都是 1，等号两边都是整式的方程叫做一元一次方程。

**标准形式**：$ax + b = 0$（其中 $a \neq 0$）

### 3.3 方程的解与解方程

**方程的解**：使方程左右两边相等的未知数的值

**解方程**：求方程的解的过程

### 3.4 等式的性质

**性质 1**：等式两边同时加上（或减去）同一个数（或式子），等式仍然成立。

若 $a = b$，则 $a \pm c = b \pm c$

**性质 2**：等式两边同时乘以同一个数（或除以同一个不为 0 的数），等式仍然成立。

若 $a = b$，则 $ac = bc$；若 $a = b$ 且 $c \neq 0$，则 $\dfrac{a}{c} = \dfrac{b}{c}$

### 3.5 移项

把方程中的某些项 **改变符号后**，从方程的一边移到另一边，叫做移项。

**依据**：等式的性质 1

**注意**：移项要变号！

### 3.6 解一元一次方程的一般步骤

1. **去分母** —— 乘以各分母的最小公倍数（等式性质 2）
2. **去括号** —— 去括号法则
3. **移项** —— 含未知数的项移到左边，常数项移到右边（等式性质 1）
4. **合并同类项** —— 把方程化成 $ax = b$ 的形式
5. **系数化为 1** —— 两边同除以 a（等式性质 2）

**例**：解方程 $\dfrac{2x - 1}{3} - \dfrac{5x + 1}{6} = 1$

解：去分母（两边同乘以 6）：
$$
2(2x - 1) - (5x + 1) = 6
$$

去括号：
$$
4x - 2 - 5x - 1 = 6
$$

移项：
$$
4x - 5x = 6 + 2 + 1
$$

合并同类项：
$$
-x = 9
$$

系数化为 1：
$$
x = -9
$$

### 3.7 列方程解应用题的一般步骤

1. **审题** —— 弄清题意，找出已知量和未知量
2. **设元** —— 用字母表示未知数
3. **找等量关系** —— 分析题意，找到等量关系
4. **列方程** —— 根据等量关系列出方程
5. **解方程** —— 求出未知数的值
6. **检验作答** —— 检验是否符合实际意义，写出答案

### 3.8 常见应用题类型

#### 行程问题

- 路程 = 速度 × 时间
- 相遇问题：$s_1 + s_2 = s_{\text{总}}$
- 追及问题：$s_{\text{快}} - s_{\text{慢}} = s_{\text{差}}$

#### 工程问题

- 工作总量 = 工作效率 × 工作时间
- 各部分工作量之和 = 1

#### 销售问题

- 利润 = 售价 - 进价
- 利润率 = 利润 ÷ 进价 × 100%

#### 分配问题

- 总数量不变，按比例分配

#### 数字问题

- 用数位上的数字表示数
- 两位数 = 十位数字 × 10 + 个位数字

## 第四章 几何图形初步

### 4.1 几何图形

**立体图形**：各部分不在同一个平面内的图形（如长方体、球、圆柱、圆锥等）

**平面图形**：各部分都在同一个平面内的图形（如三角形、圆、四边形等）

**从不同方向看立体图形**：
- 从正面看（主视图）
- 从左面看（左视图）
- 从上面看（俯视图）

### 4.2 点、线、面、体

**几何体的构成**：
- 体由面围成
- 面与面相交形成线
- 线与线相交形成点

**点动成线，线动成面，面动成体**

### 4.3 直线、射线、线段

#### 直线

- 经过两点有一条直线，并且只有一条直线（两点确定一条直线）
- 直线没有端点，向两边无限延伸
- 表示方法：直线 AB 或直线 l

#### 射线

- 直线上一点和它一旁的部分叫做射线
- 射线有一个端点，向一边无限延伸
- 表示方法：射线 OA（O 为端点）

#### 线段

- 直线上两点之间的部分叫做线段
- 线段有两个端点，有长度
- 表示方法：线段 AB 或线段 a

**两点之间，线段最短**。连接两点间的线段的长度叫做这两点的距离。

#### 线段的中点

把一条线段分成两条相等线段的点叫做线段的中点。

若 C 是 AB 的中点，则 $AC = BC = \dfrac{1}{2}AB$。

### 4.4 角

有公共端点的两条射线组成的图形叫做角。这个公共端点叫做角的顶点，这两条射线叫做角的边。

**角的表示方法**：
- 用三个大写字母表示（∠AOB）
- 用一个大写字母表示（∠O）
- 用数字表示（∠1）
- 用希腊字母表示（∠α）

**角的度量**：1° = 60′，1′ = 60″

**角的分类**：
| 类型 | 度数范围 |
|------|---------|
| 锐角 | 0° < α < 90° |
| 直角 | α = 90° |
| 钝角 | 90° < α < 180° |
| 平角 | α = 180° |
| 周角 | α = 360° |

#### 角平分线

从一个角的顶点出发，把这个角分成两个相等的角的射线，叫做这个角的平分线。

#### 余角和补角

**余角**：两个角的和为 90°，这两个角互为余角。

∠1 + ∠2 = 90° ⇒ ∠1 与 ∠2 互余

**补角**：两个角的和为 180°，这两个角互为补角。

∠1 + ∠2 = 180° ⇒ ∠1 与 ∠2 互补

**重要性质**：
- 同角（或等角）的余角相等
- 同角（或等角）的补角相等

## 精选练习题

### 有理数部分

1. 计算：$(-2)^3 + (-3) \times [(-4)^2 + 2] - (-3)^2 \div (-1)$

2. 已知 $|a| = 5$，$|b| = 3$，且 $|a - b| = b - a$，求 $a + b$ 的值。

3. 若 $a$、$b$ 互为相反数，$c$、$d$ 互为倒数，$m$ 的绝对值是 2，求 $\dfrac{a + b}{m} + m^2 - cd$ 的值。

### 整式部分

4. 化简：$3x^2 - [7x - (4x - 3) - 2x^2]$

5. 先化简，再求值：$2(a^2b + ab^2) - 3(a^2b - 1) - 2ab^2 + 1$，其中 $a = -1$，$b = 2$。

### 方程部分

6. 解方程：$\dfrac{3x + 1}{2} - \dfrac{5x - 2}{3} = 1$

7. 某商店将进价为 100 元的商品按标价的 8 折出售，仍可获利 20%，求该商品的标价。

8. 甲乙两地相距 240km，一辆汽车从甲地开往乙地，前一半时间的平均速度为 60km/h，后一半时间的平均速度为 40km/h，求汽车从甲地到乙地所用的时间。

### 几何部分

9. 如图（文字描述）：C 是线段 AB 上一点，M 是 AC 的中点，N 是 BC 的中点。若 AB = 12cm，求 MN 的长度。

10. 一个角的补角是这个角的余角的 3 倍，求这个角的度数。

## 参考答案

1. 原式 $= -8 + (-3) \times (16 + 2) - 9 \div (-1) = -8 + (-3) \times 18 + 9 = -8 - 54 + 9 = -53$

2. 由 $|a - b| = b - a$ 知 $b \geq a$，且 $a = \pm 5$，$b = \pm 3$，只有 $a = -5$，$b = \pm 3$ 满足条件。所以 $a + b = -2$ 或 $-8$。

3. $a + b = 0$，$cd = 1$，$m = \pm 2$，$m^2 = 4$，原式 $= 0 + 4 - 1 = 3$

4. $3x^2 - [7x - 4x + 3 - 2x^2] = 3x^2 - 7x + 4x - 3 + 2x^2 = 5x^2 - 3x - 3$

5. 化简得 $-a^2b + 4$，代入得 $-(-1)^2 \cdot 2 + 4 = -2 + 4 = 2$

6. $x = \dfrac{5}{3}$

7. 设标价为 x 元，$0.8x - 100 = 100 \times 20\%$，解得 $x = 150$ 元。

8. 设所用时间为 t h，$60 \cdot \dfrac{t}{2} + 40 \cdot \dfrac{t}{2} = 240$，解得 $t = 4.8$ h。

9. $MN = MC + CN = \dfrac{1}{2}AC + \dfrac{1}{2}BC = \dfrac{1}{2}(AC + BC) = \dfrac{1}{2}AB = 6$ cm

10. 设这个角为 x°，$180 - x = 3(90 - x)$，解得 $x = 45$，即这个角为 45°。
