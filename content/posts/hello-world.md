## 为什么开始写博客

一直想有一个属于自己的地方来记录思考和学习的点滴。经过一番折腾，终于用 Next.js 搭建了这个博客。

写作是最好的思考方式。把模糊的想法变成清晰的文字，这个过程本身就很有价值。

## 技术栈

这个博客使用了以下技术：

- **Next.js** - React 全栈框架，App Router 模式
- **Tailwind CSS** - 原子化 CSS 框架
- **Markdown** - 用 Markdown 写文章，简单又专注
- **Vercel** - 免费部署，自动构建

## 代码示例

写一个简单的 TypeScript 函数：

```typescript
function greet(name: string): string {
  return `你好，${name}！欢迎来到我的博客。`;
}

console.log(greet("访客"));
```
